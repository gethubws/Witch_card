# ⚔️ 战斗系统重构计划

> 日期: 2026-05-04  
> 目标: 编队系统 + 卡片对战 UI + CSS 动画

---

## 一、当前问题

| # | 问题 | 影响 |
|---|------|------|
| 1 | **无法自选编队** — `startBattle` 自动取背包前3张卡，不能选人/换位 | 核心玩法缺失 |
| 2 | **战斗界面纯文本** — 无卡面、无立绘、无前后排视觉区分 | 不可接受 |
| 3 | **无战斗动画** — 攻击/受击/击败无任何反馈，像在看 log 文件 | 缺乏游戏感 |
| 4 | **怪物信息不可见** — 战斗中看不到怪物属性/技能 | 决策盲目 |
| 5 | **日志不可读** — 只显示3条，opacity 50% | 形同虚设 |
| 6 | **前排承伤未实现** — 怪物AI随机选目标，前后排无区别 | 战术无意义 |
| 7 | **只支持单怪物** — 框架支持但从未测试多怪 | 副本枯燥 |

## 四、CSS 动画设计

### 4.1 卡片入场
```
@keyframes cardDeal
  从底部滑入 + 轻微旋转 → 到位静止
  每张卡延迟 100ms，形成"发牌"感
```

### 4.2 攻击
```
@keyframes cardStrike
  卡面 → 向目标冲刺 translate(目标坐标)
  → 到达时 scale(1.15) + 冲击波
  → easeOut 弹回原位
  约 400ms
```

### 4.3 受击
```
@keyframes cardShake
  translateX(±4px) 快速往返 4 次
  + 红色 flash 叠加层
  约 300ms
```

### 4.4 暴击
```
@keyframes critFlash
  屏幕边缘短暂红色光晕
  + 伤害数字放大弹出
  + 卡面 scale(1.2) 白闪后恢复
  约 500ms
```

### 4.5 击败
```
@keyframes cardDefeat
  rotateY(180deg) → scale(0) → opacity(0)
  卡牌翻转消失
  约 500ms
```

### 4.6 治疗
```
@keyframes healFlow
  绿光粒子从施法→目标
  + 目标卡面绿色荧光脉冲
  约 600ms
```

### 4.7 回合切换
```
@keyframes turnHighlight
  当前行动卡: scale(1.05) + box-shadow 紫色脉冲
  其他卡: scale(0.95) + opacity(0.7)
  持续到行动结束
```

## 五、战斗逻辑改进

### 5.1 前排承伤
```
怪物AI选目标概率:
  前排(主力): 60%
  辅助A:      20%
  辅助B:      20%
```

### 5.2 多怪战斗
- 每个敌人在 enemyTeam 中独立
- 玩家选目标时显示所有活着的敌人
- 怪物行动按速度排序，逐个行动
- 所有敌人行动结束后进入下一回合

### 5.3 回合流程
```
回合开始 → 当前卡选技能/目标 → 执行(含动画)
→ 下一个活着的敌人行动(含动画)
→ ... 所有敌人行动完
→ 下一张玩家卡行动
→ 所有玩家卡行动完 → 回合+1
```
